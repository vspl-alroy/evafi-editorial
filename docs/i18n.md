# Translations

Articles are written in English: `content/<slug>.md`, served at `/<slug>/`.
A translation is a hand-written file with **the same filename** in a folder named after the language:
`content/es/<slug>.md`, served at `/es/<slug>/`.

## Rules
- Same filename (slug) as the English article. Images stay shared: use the same `images/...` paths.
- Keep `{State}` tokens, numbers, image lines and the structure (`#` title, `##` sections, `-` bullets, `1.` steps) the same as the English file.
- An article with no translation is simply absent from `/es/`. The English and Spanish pages link to each other when both exist (language switcher + `hreflang`).
- UI text (footer, buttons, date line) is in `src/i18n.ts`.
- Set `GATSBY_SITE_URL` (build env) to the real domain so `hreflang` URLs are absolute and correct. It defaults to `https://vspl-alroy.github.io`.

## New language
Add the code to `locales` and a block to `ui` in `src/i18n.ts`, then add files under `content/<code>/`.
