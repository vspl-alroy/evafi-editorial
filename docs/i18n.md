# Languages

The site is English only: articles are `content/<slug>.md`, served at `/<slug>/`. UI text (header, footer, buttons, date line) is in `src/i18n.ts`.

## Adding a language later
Add the code to `locales` and a block to `ui` in `src/i18n.ts` (every UI string, including the footer link labels), then put translated articles in `content/<code>/<slug>.md` with the same file name as the English one, served at `/<code>/<slug>/`. Footer pages with their own text (`src/components/pages/`) need a branch per language. Machine-written text is a draft until a native speaker reviews it.
Set `GATSBY_SITE_URL` (build env) to the real domain so `hreflang` URLs are absolute and correct. It defaults to `https://relintex.github.io/evafi-editorial`.
